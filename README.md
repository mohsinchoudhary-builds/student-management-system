# Student Management System

A simple Python console app to add and view student records. Made this to practice classes and objects in Python.

## Features

- Add a student (ID, name, age, course)
- View all students
- Basic input checks (no empty fields, age must be a number)

## How to Run

```bash
python main.py
```

Needs Python 3.8 or later. No extra libraries required.

## Note

Records are stored in memory only, so they are lost when the program closes.
